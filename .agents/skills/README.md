# Active Codex skills

This directory contains only operator-accepted JASON-OS Codex skills.

Unverified ports live under `.planning/codex-skill-candidates/` and are not
available workflows. A candidate may be promoted here only after its acceptance
packet is complete, the operator explicitly approves it, and its tree hash is
recorded in `.agents/skills-acceptance.json`.

Run `npm run skills:validate` to verify the boundary.
